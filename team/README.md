# 🤝 에이전트 팀

서브에이전트가 아니라 **완전히 독립된 Claude Code 세션 4개**가 서로 직접 대화하며 협업하는 팀입니다.

- 각 팀원 = 별도 세션(탭). 자기 컨텍스트·작업 이력을 독립적으로 가짐.
- 팀원끼리 직접 대화 = `send_message` 도구(상대 세션에 "From {제목}" 사용자 턴으로 도착).
- 공유 상태 = 같은 작업 폴더의 `team/보드.md`, `team/로스터.md` 파일(진실의 원천).

## 팀 구성

| 역할 | 세션 이름 | 브리핑 파일 | 하는 일 |
|------|-----------|-------------|---------|
| 🧭 팀리더 | `리더` | [00_팀리더.md](00_팀리더.md) | 조율·배정·통합·중재 |
| 👨‍💻 개발자 | `개발자` | [01_개발자.md](01_개발자.md) | 백엔드·프론트엔드·DB 등 실제 작업 |
| 📑 RFP 검증자 | `RFP검증` | [02_RFP검증자.md](02_RFP검증자.md) | 요구사항 확인·전달, 작업물 검토 |
| 🔍 코드 분석자 | `코드분석` | [03_코드분석자.md](03_코드분석자.md) | 변경 근거 리포트 + 보안·리스크 리포트 |

## 팀 가동 방법 (3단계)

### 1. 팀리더 세션 준비
팀리더 역할 세션 하나를 이 폴더에서 엽니다(또는 기존 세션을 리더로 사용).

### 2. 팀원 세션 3개 열기
Claude Code에서 **새 세션(탭) 3개**를 엽니다. 각 세션은 반드시 **같은 작업 폴더**여야 합니다:
```
C:\Users\Com\Documents\cbtNewSystem
```
각 새 세션에 아래 한 줄만 붙여넣으면 됩니다:

- 개발자 세션: `team/01_개발자.md 를 읽고 그 역할대로 팀에 합류해줘.`
- RFP검증 세션: `team/02_RFP검증자.md 를 읽고 그 역할대로 팀에 합류해줘.`
- 코드분석 세션: `team/03_코드분석자.md 를 읽고 그 역할대로 팀에 합류해줘.`

> 각 탭 이름을 역할명(리더/개발자/RFP검증/코드분석)으로 바꿔두면 리더가 훨씬 정확히 식별합니다.

### 3. 팀리더에게 시작 지시
팀리더 세션에 목표를 주세요. 예: `문항 등록 API를 RFP에 맞춰 구현해줘.`
리더가 팀원을 발견하고 작업을 배분한 뒤, 팀원끼리 직접 대화하며 진행합니다.
