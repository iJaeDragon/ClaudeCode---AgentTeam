1. 
~\.claude\settings.json 파일에 아래 내용 추가

{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}


2. 설정을 추가한 뒤에는 Claude Code를 새로 실행하여 Claude Code 안에서 자연어로 에이전트 팀 생성 요청

 - 에이전트 팀 생성해줘 - 서브에이전트가 아니라 완전히 독립된 여러 세션을 사용하면서 팀원끼리 직접 대화를 하는 에이전트 팀을 만들어줘 ✓
 - 이 에이전트 팀이 주로 할 일(도메인) : 시스템 설계/개발 [아키텍처·백엔드·프론트·DB 등 실제 구축을 나눠 맡는 개발 팀] ✓
 - 팀 협업 구조 : 
      - 리드 + 팀원(오케스트레이터) - 한 세션이 팀장 역할로 작업 분배·취합, 나머지는 담당 영역 수행. 현재 세션을 팀장으로 사용 ✓
      - 완전 수평(P2P) - 팀장 없이 각자 대응하게 서로 직접 메시지로 조율. 자율적이지만 중복 가능
 -  역할 분담
    * 팀리더
    * 개발자 : 백엔드, 프론트엔트, DB 등 작업 수행
    * RFP 검증자 : 요구사항 문서를 확인하고 개발자가 작업할때 내용을 알려주거나 혹은 작업한 내용을 검토하는 역할
    * 코드 분석자 : 코드의 변경된 부분을 파악하고 보고서로 생성 (어떠한 이유로 변경됐고 이렇게 변경된 근거 등, 변경된 소스 포함) 및 보안취약점과 향후 리스크 보고서를 작성 (보고서 두개 포맷 자율)

3. ~\team 경로에 각 역할 디렉토리에서 .md파일 내용 보완

4. (팀 가동) 역할 만큼 세션을 만들어서 역할을 지정한다. [신규 세션 생성 후 자연어로 역할 지정 ex) team/01_개발자.md 를 읽고 그 역할대로 팀에 합류해줘.]
